
# Muhammad Jaffar Raza – Portfolio

Personal portfolio website for a Senior Odoo ERP Developer.

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts

No frameworks or paid dependencies required.

## Folder Structure

jaffar-portfolio/
│
├── index.html
├── styles.css
├── script.js
├── README.md
│
└── assets/
    └── Jaffar_Raza_CV.pdf

## How to Run

1. Download or create the project folder.
2. Add all source files.
3. Create an assets folder.
4. Place your CV PDF inside assets.
5. Open index.html in your browser.

## Updating Your Information

Edit index.html to update:

- Professional summary
- Contact details
- Technical skills
- Professional experience
- Project descriptions
- Education

Edit styles.css to change:

- Colors
- Fonts
- Layout
- Spacing
- Responsive design

## Adding New Projects

Find the PROJECTS section in index.html.

Copy an existing project-card article and paste it
inside the projects-grid container.

Update the following:

- Project number
- Project category
- Project title
- Project introduction
- Business requirement
- Your contribution
- Technical approach
- Technologies

## CV

Replace assets/Jaffar_Raza_CV.pdf with your latest CV.

Keep the filename unchanged unless you also update
the download link in index.html.

## Deployment

The website can be deployed using:

- GitHub Pages
- Netlify
- Cloudflare Pages

All are suitable for a static HTML/CSS website.
